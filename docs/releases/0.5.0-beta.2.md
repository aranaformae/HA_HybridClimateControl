# 0.5.0-beta.2 — Safe simulation and Frank Energie

**Simulation-only prerelease. Physical heating control is disabled, including existing installations that previously enabled live control.** Previously written Daikin/Plugwise setpoints are not reset automatically; inspect those separately before upgrading. Existing pump control, overrun automation and independent bathroom regulation remain authoritative.

## Added
- Dry Run using measured room temperature and Virtual mode with eight adjustable scenario inputs.
- Diagnostic sensors, a bounded decision log and downloadable diagnostics.
- Configurable Frank Energie all-in electricity/gas sensors and future hourly/quarter-hour price lists.
- Estimated COP/CV-efficiency options and advisory costs per kWh heat: electricity/COP and gas/(9.77 × efficiency).
- Config Flow / Options Flow, entry reload/unload cleanup and English/Dutch setup text.

## Reliability
- No physical service-call path, including with legacy live-control/pump flags.
- Reject invalid, unavailable, nonfinite, stale and non-Celsius room data.
- Reject unsupported tariff units and invalid/expired schedules; handle timezone-aware price periods and negative electricity prices.
- Restore thermostat target only; begin OFF after reload or simulation-mode changes.

## Install with HACS
Add https://github.com/aranaformae/HA_HybridClimateControl as a custom Integration repository. Enable prereleases for this repository and select 0.5.0-beta.2. Restart Home Assistant, then add or configure Hybrid Climate Controller under Devices & Services.

Minimum declared Home Assistant version: 2026.2.0. Automated tests use HA 2026.2.3 / Python 3.13; newer releases and physical equipment have not been tested. Select your Plugwise room climate entity (current_temperature) and Frank all-in import-price entities in Configure. No Frank credentials are needed by this controller.

## Validation and limitations
36 local tests passed. Publication is gated on Python tests, Ruff, syntax, Hassfest and HACS validation. The release tag exactly matches manifest.json. No thermal learning, economic actuation or MPC is implemented. Energy comparison is advisory; trend and floor heat remain scenario inputs. Do not use this prerelease as a physical heating or safety controller.
